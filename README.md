# 🏪 超市商品管理系统

一个前后端分离的超市商品管理平台，支持收银结账、商品采购、库存管理、员工管理、销售统计等功能。

---

## 🛠 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React + Ant Design + Axios |
| 后端 | Spring Boot + Spring Security + JWT |
| 数据库 | H2（内存模式，可快速切换至 MySQL） |
| 构建工具 | Maven（后端）、npm（前端） |

---

## ✨ 功能模块

- **收银员**：商品浏览、购物车、结账找零
- **采购员**：供货商管理、创建采购单
- **库存管理员**：入库确认、库存查询、库存预警、分类管理
- **经理**：员工账户管理、销售记录与统计
